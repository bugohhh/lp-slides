線性規劃是什麼？

在有限資源下，找出讓目標最好的決策。

  • 目標和限制都必須是線性的：每個變數只出現一次方，不會有 x² 或 x·y
  • 常見用途：生產規劃、運輸排程、人員指派、資源分配
  • Dantzig 的經典例子：70 個人分配 70 份工作，窮舉不可能，LP 很快就能解出

寫模型只要回答三個問題

① 決策變數

我要決定什麼？

x1, x2, …

② 目標函數

我要讓什麼最好？

max / min z

③ 限制式

我被什麼限制？

… ≤ 資源量，x ≥ 0

滿足所有限制的一組答案叫可行解。

動手：把手搖飲店寫成模型

x1 = 奶茶桶數，x2 = 紅茶桶數

max  z = 300x1 + 200x2      ← 利潤
s.t.  x1 +  x2 ≤ 50        ← 茶葉
      2x1       ≤ 60        ← 牛奶
      x1 + 2x2 ≤ 80        ← 工時
      x1, x2 ≥ 0

可行域：所有可行解圍出的區域

  • 把每條限制畫成一條線，全部重疊的地方就是可行域
  • 它是一個沒有凹洞的多邊形
  • 關鍵事實：最佳解一定可以在某個頂點（角落）找到
  • 所以不用檢查無限多個點，只要檢查角落！

變數一多，電腦怎麼解？單純形法

  1. 用鬆弛變數把 ≤ 變成 = （鬆弛變數 = 沒用完的資源）
  2. 從一個頂點出發
  3. 找一條能讓利潤變大的邊，走到相鄰頂點（這一步叫樞紐運算）
  4. 沒有更好的邊 → 目前就是最佳解

Dantzig 在 1947 年為美國空軍發明。最壞情況很慢，但實務上非常快。

LP 小歷史

  • 1820 年代 Fourier 研究線性不等式
  • 1939 Kantorovich 研究生產規劃
  • 1947 Dantzig 發明單純形法；von Neumann 提出對偶理論
  • 1975 Kantorovich、Koopmans 獲諾貝爾經濟學獎
  • 1979 Khachiyan 橢球法：理論上快，實務上慢
  • 1984 Karmarkar 內點法：理論與實務都快

附贈的答案：資源值多少錢？

每個 LP 都有一個雙胞胎叫對偶問題，它的解就是每種資源的影子價格。

資源影子價格意思
茶葉200 元/包多 1 包，最多多賺 200
牛奶50 元/公升多 1 公升，最多多賺 50
工時0本來就有剩，再多也沒用

兩邊最佳值都是 13000（強對偶）。

如果答案一定要是整數？

  • LP 允許小數，例如解出「0.7 台火車頭」
  • 如果一定要整數，就變成整數規劃，一般難解很多
  • 規模夠大時，四捨五入通常就夠用
Wiki 來源：整數規劃、四大假設14 / 15

重點回顧

  1. LP = 線性目標 + 線性限制，在有限資源下求最好
  2. 建模三步：決策變數 → 目標函數 → 限制式
  3. 先確認四大假設
  4. 最佳解在可行域的頂點：兩個變數用圖解法，更多用單純形法
  5. 對偶問題告訴你資源的影子價格
